# Delivery Tasks

Files in this directory describe implementation sequencing and verification evidence, not the
product contract. Active work may keep a plan and checklist here. Once work is merged, remove
completed delivery artifacts unless they are required for an audit; Git history and the pull request
retain the record.

Durable behavior belongs in [`docs/specs/`](../docs/specs/). Durable technical rationale belongs in
[`docs/decisions/`](../docs/decisions/).
